# 薄肌俱乐部功能优化与新增开发方案

本方案以《薄肌俱乐部功能点清单》为基准，逐行覆盖其中的优化意见和新增意见。合并表述的意见在同一行中分别提出实现和验证方法；开发时可按分号拆分任务。方案是建议设计，尚未实施或验证；“实际结果”统一标为“待执行”，不代表测试已通过。

## 项目现状与实施约定

- 当前前端为 Vue 3 + Vite，后端为 FastAPI；账号数据通过 `/api/v1/data` 的 revision 实现冲突检测，正式登录使用 Cookie 和 CSRF 校验。现有页面、API、模型和测试位于 `frontend/src/views`、`backend/app/api`、`backend/app/models`、`frontend/tests` 和 `backend/tests`。
- 优先复用现有记录、接口和指标计算逻辑；涉及字段或表变更时制定版本化迁移、旧数据默认值和回滚方案。跨设备写入沿用 revision，冲突时提示用户处理，不静默覆盖。
- 所有用户私有数据按账号隔离，写接口做服务端校验和权限检查；外部服务密钥只放服务端。对外调用、通知、支付等需配置测试环境，不能用演示结果冒充真实结果。
- 表中测试步骤为建议验收步骤，除特别注明外均在隔离测试账号与测试数据中执行；涉及外部渠道时同时验证成功、失败与重试。涉及时间的统计应统一用户时区和周起止规则。
- 未确定的阈值、排名口径、提醒频率、内容审核和商业规则应先由产品确认；以下给出可落地的默认方向，不视为已定需求。
