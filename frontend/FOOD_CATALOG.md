# 食品目录与热量评估

饮食管理页包含分类目录、每克/每100克热量、当天食品组合，以及碗、个、片、杯的参考份量。支持搜索名称与别名（例如“馍”“面包”），称重或修改每单位克重后计算。确认前是临时组合，离开页面会清空；确认后写入现有饮食记录，沿用本地持久化、账号同步、编辑和撤销功能。

## 数据来源

- 提供者：台湾卫生福利部食品药物管理署，食品营养成分资料集。
- 官方目录与授权说明：https://data.gov.tw/dataset/8543
- 下载地址：https://data.fda.gov.tw/data/opendata/export/20/json
- 授权：政府资料开放授权条款第1版。页面保留来源说明及官方链接。
- 本地快照：`src/data/food-catalog.json`，包含获取日期、原始数据 SHA-256、原名、来源编号及营养值。
- 本次导入2160种热量、粗蛋白、总碳水化合物、粗脂肪字段完整的食品，均按100克可食部分计；缺失值不当作零值补齐。
- 名称转换为简体，并在 `src/food-catalog.js` 增补常用名称和别名。

每克热量 = 每100克热量 / 100。组合按实际克重累加原始值，显示时再取舍小数。生熟状态和加工描述可在食品卡片展开查看。

## 份量估算

本应用的参考份量：一碗米饭150g、一碗熟面250g、一个白馒头100g、一片吐司30g、一个水煮鸡蛋50g、一杯牛奶250g。以上均可修改，不代表统一标准。饮料也按克重计算，不自动将毫升等同克。

熟面条是明确标注的配方估算：以来源编号 `R2000101` 的干面条为基础，假设煮后重量为原来2.5倍，100g熟面含40g干面与60g吸收的水。未包括汤、浇头、酱料和额外用油。

混合菜肴与原料不要重复计入。热量值是参考估算，不是针对用户餐食的实测值。

记录保留每100g营养基准，`portion = 食用克重 / 100`，备注保存克重、单位假设与来源编号。单项最多5000g，一次组合最多50项；确认后清空草稿，避免重复提交。编辑或复制到手动表单时，转换为本次实际摄入的一份营养值（保留一位小数）。

## 更新数据

在前端目录执行（仅更新工具需要Python，网页运行不依赖Python或第三方实时接口）：

```powershell
python -m pip install opencc-python-reimplemented
python scripts/import-food-catalog.py
```

也可以提供已经下载解压的JSON文件路径。更新后检查来源变更及份量引用的编号，再运行 `npm run test:unit`、`npx playwright test tests/food-catalog.spec.js` 和 `npm run build`。
